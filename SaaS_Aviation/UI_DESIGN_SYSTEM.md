# UI Design System

## Design Read

Professional aviation ERP for daily use. Dense, fast, precise, searchable, keyboard-friendly, and calm.

## Layout

- Desktop-first responsive ERP shell.
- Persistent sidebar for modules.
- Topbar with tenant, global search, work queue, and user/session controls.
- 360 workspaces for company, part, and stock entities.
- Sticky contextual actions on detail pages.

## Visual Language

- Restrained neutral interface with aviation red accent used for focus and critical status only.
- Red is not used for create actions.
- Cards are compact panels, not decorative blocks.
- Tables should expose important context without hiding everything behind row clicks.

## UX Rules

- Everything critical should be visible.
- Prefer fewer clicks and less vertical scrolling.
- Use tabs/sections only when they reduce cognitive load.
- Use status badges for aviation workflow states.
- Always distinguish Owner / Company, Supplier, Tag Info, and Traceability.
