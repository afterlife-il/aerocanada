# AI Architecture

## Planned Shape

- Retrieval over tenant-scoped ERP records.
- Tool layer for search, quote drafting, RFQ drafting, and document analysis.
- Human approval for all mutations.
- Audit log for AI suggestions and accepted actions.

## Entry Points

- Global assistant in topbar.
- Entity assistant on Company 360, Part 360, Stock 360.
- Quote/RFQ drafting assistant.
- Supplier recommendation panel.

## Not Implemented Yet

No LLM provider, embeddings, vector store, or autonomous agent behavior is implemented in this foundation.
