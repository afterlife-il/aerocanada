# SaaS Roadmap

## Phase 1: Foundation

- Separate Next.js + API monorepo.
- Legacy adapter interfaces.
- Auth and audit abstractions.
- ERP shell and first 360 pages.

## Phase 2: Legacy Read Integration

- Read-only MySQL adapter.
- Data dictionary coverage.
- Query performance review.
- Module-by-module comparison against Yoyamic screens.

## Phase 3: Auth and Tenant Foundation

- Provider decision.
- Employee identity bridge.
- Tenant/company workspace model.
- RBAC and audit log persistence.

## Phase 4: Workflow Modernization

- RFQ to quote to PO workflow.
- Stock 360 and lifecycle movement timeline.
- Repair/exchange/lease flows.

## Phase 5: Analytics and AI

- KPI dashboards.
- Operational assistant with retrieval over ERP data.
- Pricing, supplier, and follow-up recommendations.
